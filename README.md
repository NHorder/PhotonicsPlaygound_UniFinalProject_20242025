# Photonics Playground

## Introduction
This project describes a light based 2D puzzle educational game with the purpose and aim of introducing fundamental concepts of light through interactive play. The result of this project will be a game containing several levels that introduce users to various concepts and challenge them to use that knowledge in order to complete the level. The theme of this game is “Space”, as this allows for a more consistent ‘story’ and larger environment to briefly introduce wider concepts, such as space debris

## Outcomes

The outcome of this project will include:
- A WebGL project
- A Report containing project process and features
- Assoficated diagrams alongside the report
- Further documentation
- A Citation document

A final build of the game can be found at: https://outreach-hub.aber.ac.uk/Physics/PhotonicsGame/WebGL_Build/index.html
This will be available until 2027.

## Software and Hardware requirements

As Player / User
- A search engine of any kind and the link to the html page that the game will be displayed on

As Developer
- Unity 2022.3.50f1

## Notes for Developers

This project has been designed in a way that would allow a developer to easily create custom variations of satellites and create new levels. All satellites and UI features have been saved in respective prefabs and can be imported into levels and retain the same functionality.
